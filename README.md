# Bug Tracker

Next.js bug tracker: bug CRUD with comments, events and related bugs, bulk operations, search, import/export, activity feed and burndown API, stored with Prisma.

> **See also:** [IB4G-bugTracker](https://github.com/siamand-shirzad/IB4G-bugTracker) is the continued version of this project (IB4G report parser, Docker deployment).

باگ‌ترکر با Next.js و Prisma. نسخهٔ ادامه‌دار آن IB4G-bugTracker است.

## Stack
Next.js · TypeScript · Prisma · shadcn/ui · TanStack Query / Table · Zod · Recharts

## Run
```bash
npm install
npm run db:push
npm run dev
```
Deployment notes: [DEPLOYMENT.md](DEPLOYMENT.md).
